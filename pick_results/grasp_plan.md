# 螺栓杆身抓取方案

模型：螺栓.FCStd。抓杆身，避开大头。模型杆身外径 21 mm。
张开设定：20 mm；夹持杆身设定：9.43 mm（用户已确认夹住时的指令值）。
选中候选簇：7；模型匹配分：0.861；拟合误差：1.15 mm。
杆身抓点（模型坐标，mm）：[0.0, 0.0, 34.54]。
抓取中心（相机坐标，mm）：[-2.23, 151.96, 253.41]。
距非模型场景点的最小距离：16.10 mm，仅用于排序，尚未验证夹指碰撞。
home 释放 TCP 位姿（mm / deg）：[-90, -180, 280, 180, 0, 90]。

动作顺序：拍照 → 张开 → 对准杆身 → 下降 → 夹持 → 抬升 → 确认夹牢 → 移到 home 上方 → 下降到 home → 张开释放 → 退回 → 再次拍照。

已计算机器人位姿。实际执行仍需核对可达性、夹指与料框碰撞及现场状态。
