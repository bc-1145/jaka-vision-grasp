# 台面自动抓取并竖放

双击工作区的 `一键台面竖放.bat`，执行一轮：确认空爪 → 高处总览 → 本次视觉选件 → 管身中部夹取 → 抬升验证 → 移到台面中部 → 大法兰朝下竖放 → 松爪退开 → 总览验证。脚本不修改现有 Home，也不自动写入标定参数。

当前安装必须保持相机、夹指、TCP 和工具坐标不变。桌面工作区与放置区域保存在 `table_automation.json`，放置 XY 为 `[43,-537]` mm，Z 从每次采集的桌面点云重新计算。初始夹爪应为空，工具号与用户坐标应匹配已保存的总览位。脚本用已保存的空爪参考检查夹持空间；被遮挡或光照不足时停止。此检查不能观察隐藏空间，不能替代正确的初始现场状态。

命令均在工作区根目录运行：

```powershell
# 离线核对配置和参考图，不连接硬件
.\.camera-runtime\python.exe -X utf8 auto_table_upright.py --check

# 相机与控制器只读检查，机械臂须已在总览位
.\.camera-runtime\python.exe -X utf8 auto_table_upright.py --observe

# 新扫描及控制器逆解/正解规划，不发送动作
.\.camera-runtime\python.exe -X utf8 auto_table_upright.py --plan-only

# 执行一次自动流程
.\.camera-runtime\python.exe -X utf8 -u auto_table_upright.py --execute
```

每轮单独保存到 `pick_results/automatic_table/run_年月日_时分秒/`：`run.json`、阶段日志、扫描点云、方案、彩色图和原始毫米深度图。旧记录只用于审计，不能用于自动续跑。失败后保留实际夹爪状态，重新观察现场再启动；不自动重发不确定的动作指令。

## 监督和纠正

- 本次点云独立检查大法兰宽环方向；发现反向时，只有反向 CAD 完整支持和宽端证据同时通过，才纠正轴向。方向不明确时最多重新扫描两次。
- 接近时检查实际管身和头部外观，并排除固定夹爪轮廓。未对齐不发送闭合。
- 从抓点先抬升 60 mm，再抬升到 90 mm。真实夹持反馈可用时要求连续反馈；未映射时必须同时看到零件、确认零件相对腕部相机静止且周围桌面移动。单幅黑影、数学坐标对齐和 8.65 mm 设定回读均不能确认夹住。
- 翻正后、下降前和松爪前重新检查持物状态。夹持不确定时停止，保留夹爪。
- 台面边侧抓起后先保持抓姿平移到中部高位，再翻正，避免在边侧强行翻转。规划检查 MoveL 的实际笛卡尔路径、MoveJ 的关节路径、返回总览路径和持件 CAD 与桌面的采样净空；这些不等于整条机械臂的完整碰撞模型。
- 松爪退开后重新采集原生点云，检查实物高度、连续竖直管身和下方大法兰。倒下、看不清或无零件时不标记成功，不盲目重新抓取。

## 夹爪反馈

`gripper_feedback.py` 已接入慧灵 Z-EFG-20P 的输入寄存器解析，区分实际状态、位置、电流和输出设定值。目前实际 JAKA 配置没有映射 AI，因此硬件夹持反馈不可用。程序会明确写入日志，并使用上述视觉与随动监督。

若完成真实 AI 映射，可使用以下模式，反馈缺失或运行中失效均停止，不降级为纯视觉：

```powershell
.\.camera-runtime\python.exe -X utf8 auto_table_upright.py --execute --require-hardware-feedback
```

本脚本不修改扩展 IO 配置，也不复位控制器故障。夹持中心仍是开合录像估计并经过实物试抓验证的参数，不代表已完成独立计量标定。更换安装、CAD、相机投影或夹持中心后，参考绑定检查要求重新核对空爪参考与规划。
